# Ingots — Knowledge Foundry

The public collection is named **Ingots**. **Book Ingots** is the type for book-derived artefacts; the required descriptor is **“One book, poured onto one page.”**

Public URL: `/ingots/`. Old `/thoughttiles/` URLs redirect while keeping query parameters (including `?id=btt-0001`). The `btt-` identifiers and existing `images/thoughttiles/` asset paths are intentionally retained for historical compatibility. No catalogue classifications or image content were modified in the naming migration.

Metadata and social titles use `Book Ingots | Knowledge Foundry`. On-site navigation, headings and cards use `Ingots`. The individual viewer uses `The Ingot for [title]`.
