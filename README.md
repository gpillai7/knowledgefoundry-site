# Knowledge Foundry — website

Static site. Deploy with GitHub Pages (Settings -> Pages -> Deploy from branch -> main / root).

**Files**
- `index.html` — the site (single page; hash-based navigation, e.g. `/#idea`, `/#read`)
- `styles.css` — global styles (hover states, page visibility)
- `images/` — the three diagrams (PNG)
- `CNAME` — custom domain (`knowledgefoundry.org`); set your DNS to GitHub Pages

Fonts load from Google Fonts. No build step.
